## 🚀 Core Course Modules

* **[1. Advanced LaTeX Typesetting](docs/01-latex.md)**: Document architecture, configuration options, preamble setups, math environments, tables, floats, and coordinate picture drawings.
* **[2. Beamer Presentations & Visual Design](docs/02-beamer.md)**: Slide architecture, color theory (**60-30-10 color rule**), luminance contrast ratios, typography rules, and block containers.
* **[3. Automated Documentation with Doxygen](docs/03-doxygen.md)**: Execution workflows, configuration tuning (`Doxyfile`), file-level tags, method tags, and C++ docstring annotations.
* **[4. Collaborative Workflows in Google Docs](docs/04-googledocs.md)**: Real-time cloud co-authoring, Suggesting mode, contextual comment threads, version history milestones, and citations.
* **[5. Distributed Version Control with Git & GitHub](docs/05-git-github.md)**: Three-state model, categorized command reference (init, add, commit, branch, merge, push, pull), and shell script automation.
