\# 1. Introduction to LaTeX



\## Overview

\*\*LaTeX\*\* is a document preparation system built on top of TeX. Users specify the logical structure of a document using plain text and markup commands (`.tex`).



\## Document Structure

Every LaTeX document requires three core components:

\- `\\documentclass\[options]{class}` (e.g., `article`, `report`, `book`, `letter`, `exam`)

\- Preamble: packages (`\\usepackage{amsmath, graphicx, xcolor}`) and metadata (`\\title`, `\\author`, `\\date`)

\- `\\begin{document} ... \\end{document}`
