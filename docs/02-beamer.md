\# 2. Presentations with Beamer



\## Overview

\*\*Beamer\*\* is a specialized LaTeX document class (`\\documentclass{beamer}`) designed for creating structured presentation slides.



\## Core Concepts

\- \*\*Frames:\*\* Individual slides are enclosed inside `\\begin{frame}{Slide Title} ... \\end{frame}`.

\- \*\*Themes:\*\* Visual appearance is controlled globally in the preamble using `\\usetheme{Madrid}` (or `metropolis`, `Warsaw`).

\- \*\*Blocks:\*\* Highlight key takeaways using `\\begin{block}{Title} ... \\end{block}`.

\- \*\*Lists \& Overlays:\*\* Supports `itemize`, `enumerate`, incremental reveals (`\\pause`), and verbatim code blocks (using the `\[fragile]` frame option).
