\# 4. Collaborative Workflows with Google Docs



\## Overview

\*\*Google Docs\*\* is a cloud-based word processor enabling real-time multi-user collaboration and rapid document creation\[cite: 208, 209].



\## Key Features Learned

\* \*\*Real-Time Collaboration:\*\* Multi-user editing with live cursors and integrated chat\[cite: 209, 212].

\* \*\*Review Tools:\*\* Suggesting mode for tracked edits, comment threads with assign/resolve capabilities\[cite: 212].

\* \*\*Version History:\*\* Automatic timeline tracking, ability to inspect previous versions, and naming milestone states\[cite: 213].

\* \*\*Formatting \& Integrations:\*\* Built-in heading styles, tables, equations, citations (`Tools -> Citations` for APA/MLA), and Google Drive integration\[cite: 210, 215, 216, 218, 221].
